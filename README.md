# MemoryJar

A place to keep the moments worth keeping.

Drop memories into a jar. Shake it to get one back.

## Live Demo

🔗 [jasnoor-kaur1501.github.io/MemoryJar](https://jasnoor-kaur1501.github.io/MemoryJar)

## What it does

- Write a memory — a moment, a feeling, something small you don't want to forget
- Tag it with a mood: happy, grateful, funny, bittersweet, proud, or love
- Watch it drop into the jar (the slips fill up as you add more)
- Click or shake the jar to reveal a random memory
- All memories listed below with dates — click any to reveal it
- Delete memories you've outgrown
- Persists across sessions via localStorage

## Design

Caveat handwriting font + Lora serif · Warm cream, paper texture, ruled lines · Handcrafted scrapbook energy — deeply personal, tactile, analogue-feeling. Completely different from Days 01–09.

## Tech

HTML · CSS · Vanilla JS · SVG jar animation · localStorage · No API · No dependencies · GitHub Pages

## Run locally

Download or clone → open `index.html` in any browser. Done.
